# Build and Compare Hugging Face LLMs

## Overview
This project uses Hugging Face models to perform:
- Text Generation  
- Explanation  
- Summarization  
- Question Answering  

It also compares two models to evaluate their performance.

---

## Models Used
- `google/flan-t5-base`  
- `TinyLlama/TinyLlama-1.1B-Chat-v1.0`  

---

## Features
- Explain concepts in simple terms  
- Summarize text into short points  
- Answer questions using context  
- Compare outputs between models
